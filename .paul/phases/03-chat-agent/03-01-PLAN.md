# PLAN — Phase 3 / 03-01: Chat/Agent

## Decision

Settle the Phase 3 open call as:

- Move only the true shared-code chat cluster into `routes/chat/`:
  - `routes/chat_routes.py` -> `routes/chat/routes.py`
  - `routes/chat_helpers.py` -> `routes/chat/helpers.py`
- Leave `routes/shell_routes.py`, `routes/codex_routes.py`, and
  `routes/skills_routes.py` flat. They are standalone singleton route surfaces
  with separate consumers and no shared chat helper layer.

## Implementation

- Create `routes/chat/` with a docstring-only `__init__.py`.
- Preserve old import and patch paths with `sys.modules` alias shims:
  - `routes/chat_routes.py`
  - `routes/chat_helpers.py`
- Repoint `app.py` to import `setup_chat_routes` from the canonical package.
- Repoint tests that read implementation source by filesystem path to the new
  canonical files.
- Add a shim guard test proving old and new import paths are identical module
  objects, representative symbols are identical, old-path attribute assignment
  is visible through the new path, and pop/reimport re-aliases correctly.

## Verification

- Focused chat/package test cluster.
- Python compile check for moved modules, shims, and `app.py`.
- Broad local pytest gate with zero new failures vs baseline.
- `ruff check` before commit.

## Out of Scope

- No behavior changes to chat, agent loop, shell, Codex, or skills.
- No movement of `shell_routes.py`, `codex_routes.py`, or `skills_routes.py`.
- No `agent_loop.py` decomposition; that remains a later milestone.
